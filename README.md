# Tra cứu giảng viên HUST

Extension tra giảng viên theo mã lớp hoặc Teacher ID trên Cổng thông tin sinh viên HUST.

## Cài đặt

1. Tải file [`tricklo-extension-kongwoang.zip`](./dist/tricklo-extension-kongwoang.zip).
2. Giải nén file vừa tải.
3. Mở `chrome://extensions` trên Chrome hoặc `edge://extensions` trên Edge.
4. Bật **Developer mode**.
5. Chọn **Load unpacked** rồi chọn thư mục vừa giải nén.
6. Đăng nhập [Cổng thông tin sinh viên HUST](https://qldt.hust.edu.vn/students/) và sử dụng hộp **Tra giảng viên HUST** ở góc dưới bên phải.

Tác giả: **kongwoang**
