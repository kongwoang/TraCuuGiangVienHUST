# Tra cứu giảng viên HUST

Extension tra giảng viên theo mã lớp trên Cổng thông tin sinh viên HUST.

[Extension](https://github.com/kongwoang/TraCuuGiangVienHUST)

[**⬇️ Tải extension (.zip)**](https://github.com/kongwoang/TraCuuGiangVienHUST/archive/refs/heads/main.zip)

## Cài đặt

1. Bấm nút **Tải extension (.zip)** phía trên.
2. Giải nén file vừa tải.
3. Mở `chrome://extensions` trên Chrome hoặc `edge://extensions` trên Edge.
4. Bật **Developer mode**.
5. Chọn **Load unpacked** rồi chọn thư mục `TraCuuGiangVienHUST-main` vừa giải nén.
6. Đăng nhập [Cổng thông tin sinh viên HUST](https://qldt.hust.edu.vn/students/) và sử dụng hộp **Tra giảng viên HUST** ở góc dưới bên phải.
